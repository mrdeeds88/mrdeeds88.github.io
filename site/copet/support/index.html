Co-pet Privacy Terms Support

Support

Install

Co-pet runs on Windows 11 (64-bit). Install it from the Microsoft Store, then open it from the Start menu.

Updates

Updates arrive automatically through the Microsoft Store. To check now, open the Microsoft Store, go to Library and click Get updates.

Microphone

To record meetings, Co-pet needs the microphone. If recording doesn't start, open Windows Settings › Privacy & security › Microphone, make sure Microphone access is on, and allow Co-pet in the list of apps.

Your data folder

Co-pet keeps your items, files, recordings and models in %USERPROFILE%\Co-pet.

Local-only mode

In Settings › Privacy, turn on Local-only mode to stop every network call. Sync, cloud AI, exports and model downloads pause until you turn it off.

Accounts, sync and Notion/Asana sign-in

Co-pet works fully on your computer without any server. Accounts, sync between computers, and signing in to Notion or Asana with a button need a backend, and Co-pet doesn't run one for you: you connect your own free Supabase project. Notion and Asana personal tokens work without any backend: in Integrations, click Use a token instead.

To set up your own backend:

  1. Create a free project at supabase.com and install the Supabase CLI.
  2. From a copy of the Co-pet repository, link the project (supabase link --project-ref <ref>), apply the database migrations (supabase db push) and deploy the oauth and delete-account functions (supabase functions deploy oauth --no-verify-jwt, supabase functions deploy delete-account).
  3. Set the function secrets listed in supabase/README.md with supabase secrets set.
  4. For Notion or Asana sign-in, create your own Notion public integration and Asana app, and set their redirect URL to https://<ref>.supabase.co/functions/v1/oauth/callback. Their client ID and secret go into the function secrets, never into Co-pet.
  5. In the Supabase dashboard, Authentication › URL Configuration › Redirect URLs, add copet://auth/callback.
  6. In Co-pet, open Settings › Account and sync and paste your project URL (https://<ref>.supabase.co) and its publishable key.

Only ever paste the publishable key into Co-pet. Never use the service_role or secret key: it stays in your Supabase project.

Report a problem

Open an issue at github.com/mrdeeds88/co-pet/issues with what you did, what happened and your Co-pet version from Settings › About.

Deleting your data

In Settings, use Delete everything to remove all Co-pet data from your computer, or Delete cloud data to remove your synced data from your Supabase project. Uninstalling Co-pet leaves the %USERPROFILE%\Co-pet folder in place; delete it to remove downloaded models too.

Hỗ trợ

Cài đặt

Co-pet chạy trên Windows 11 (64-bit). Cài Co-pet từ Microsoft Store, sau đó mở từ menu Start.

Cập nhật

Bản cập nhật được Microsoft Store tự động cài. Để kiểm tra ngay, mở Microsoft Store, vào Thư viện và nhấn Nhận bản cập nhật.

Micrô

Để ghi âm cuộc họp, Co-pet cần dùng micrô. Nếu không ghi âm được, mở Cài đặt Windows › Quyền riêng tư & bảo mật › Micrô, bảo đảm Quyền truy cập micrô đang bật và cho phép Co-pet trong danh sách ứng dụng.

Thư mục dữ liệu

Co-pet lưu mục, tệp, bản ghi âm và mô hình trong %USERPROFILE%\Co-pet.

Chế độ chỉ trên máy

Trong Cài đặt › Quyền riêng tư, bật Chế độ chỉ trên máy để dừng mọi kết nối mạng. Đồng bộ, AI đám mây, xuất dữ liệu và tải mô hình tạm dừng cho đến khi bạn tắt.

Tài khoản, đồng bộ và đăng nhập Notion/Asana

Co-pet chạy trọn vẹn trên máy tính của bạn mà không cần máy chủ nào. Tài khoản, đồng bộ giữa các máy tính và đăng nhập Notion hay Asana bằng một nút bấm cần một backend, và Co-pet không vận hành backend nào cho bạn: bạn kết nối dự án Supabase miễn phí của riêng mình. Token cá nhân của Notion và Asana dùng được mà không cần backend: trong Tích hợp, nhấn Dùng token.

Để tự dựng backend:

  1. Tạo một dự án miễn phí trên supabase.com và cài Supabase CLI.
  2. Từ một bản sao của kho mã Co-pet, liên kết dự án (supabase link --project-ref <ref>), áp dụng các migration cơ sở dữ liệu (supabase db push) và triển khai hai function oauth và delete-account (supabase functions deploy oauth --no-verify-jwt, supabase functions deploy delete-account).
  3. Đặt các secret của function được liệt kê trong supabase/README.md bằng supabase secrets set.
  4. Để đăng nhập Notion hoặc Asana, tạo public integration Notion và ứng dụng Asana của riêng bạn, đặt redirect URL là https://<ref>.supabase.co/functions/v1/oauth/callback. Client ID và secret của chúng nằm trong secret của function, không bao giờ nằm trong Co-pet.
  5. Trong bảng điều khiển Supabase, mục Authentication › URL Configuration › Redirect URLs, thêm copet://auth/callback.
  6. Trong Co-pet, mở Cài đặt › Tài khoản và đồng bộ rồi dán URL dự án (https://<ref>.supabase.co) và publishable key của dự án.

Chỉ dán publishable key vào Co-pet. Không bao giờ dùng khóa service_role hay secret key: khóa đó chỉ nằm trong dự án Supabase của bạn.

Báo lỗi

Mở một issue tại github.com/mrdeeds88/co-pet/issues, kèm việc bạn đã làm, điều đã xảy ra và phiên bản Co-pet trong Cài đặt › Giới thiệu.

Xóa dữ liệu

Trong Cài đặt, dùng Xóa mọi thứ (mục Dữ liệu) để xóa toàn bộ dữ liệu Co-pet trên máy tính của bạn, hoặc Xoá dữ liệu đám mây (mục Tài khoản và đồng bộ) để xóa dữ liệu đã đồng bộ trong dự án Supabase của bạn. Gỡ cài đặt Co-pet vẫn giữ lại thư mục %USERPROFILE%\Co-pet; xóa thư mục đó để xóa cả các mô hình đã tải.
